\# VisionInspect AI



\## Manufacturing Defect Detection \& Quality Inspection System



VisionInspect AI is an AI-powered manufacturing quality inspection platform designed to detect product defects, classify defect types, assess severity, automate quality decisions, and provide manufacturing analytics.



\## Technology Stack



\- Frontend: Next.js, TypeScript, Tailwind CSS

\- Backend: Python, FastAPI

\- Database: PostgreSQL, MongoDB

\- Computer Vision: OpenCV

\- AI: PyTorch, YOLO

\- Machine Learning: Scikit-learn

\- Data Processing: NumPy, Pandas

\- Authentication: JWT

\- DevOps: Docker

\- Deployment: AWS / Azure
